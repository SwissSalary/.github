# SwissSalary .github Repository

This repository holds organization-wide GitHub metadata and community-facing configuration for the SwissSalary organization.

## Purpose

The `.github` repository is the central place for files that apply across repositories, such as:

- Organization profile content
- Shared community health files
- Issue and pull request templates
- Default GitHub Actions workflows
- Other governance and contribution standards
